# Проверка браузерной версии 2.5 / коррекции метода 2.0.1

Статус: автоматизированные проверки пройдены. Это отчёт об исправлении программы, не экспертная приёмка астрологической методики и не оценка точности прогноза.

## Выполнено

- 136 тестовых функций JavaScript, без ошибок. Команда: `node --test --test-isolation=none tests/*.test.mjs`.
- Все 47 исходных приёмочных случаев из корректирующего пакета реализованы под исходными ID в `tests/corrections.test.mjs`; ожидаемые значения не получены из приложения. Предоставленный файл `tests/fixtures/corrective_acceptance_v201.json` сохранён неизменным, включая его исторические метки `NOT_RUN_AGAINST_APP`.
- Дополнительно проверены два корня вокруг станции, касание точного аспекта, ретроградные возвраты, граница/узкие дома, переход XII→I, цепочка передачи, JSON Schema, запрет поддельных прогнозов, сохранение старого численного снимка и границы ±65°.
- 7 независимых численных сценариев: 4 карты хронологии, антисция без точного телесного аспекта, Солнце у горизонта, перенос перед куспидом. Эталон создан отдельным Python-кодом с pyswisseph 2.10.03 / Moshier, без вызовов JS-движка; код воспроизведения — `scripts/qa/corrective-reference.py`, замороженный эталон — `tests/fixtures/corrective_independent_ephemeris.json`. Допуск времени 2 с определён до сверки; угловой допуск указан в тестах.
- 619 исходных Python-тестов v1.1–v1.9: 164 / 46 / 38 / 45 / 65 / 54 / 83 / 54 / 70, ошибок нет. Базовая браузерная версия v1.0 проверяется JS-наборами движка, форм, схем и архива. Отдельный методический пакет v2.0 не предоставлен, его проверка не заявляется.
- Сохранены прежние полные сравнения с Python: 67 маршрутов v1.7, 38 сценариев отношений v1.8, 54 карьерных случая v1.9; численные эталоны v1.4/v1.5 и чистые контракты v1.1/v1.2 также проходят.
- Промышленная сборка `npm run build`, статические валидаторы без runtime-компиляции схем и `git diff --check`.

## Независимые карты хронологии

Время задано юлианскими днями UTC в приложенном эталоне. Во всех четырёх картах точный аспект и ингресс попадают в один исходный трёхчасовой шаг.

| Начало JD | Пара | Порядок по Python | Исправленный флаг смены знака до аспекта |
|---|---|---|---|
| 2460683.346363992 | Луна / Меркурий | Аспект раньше ингресса | false; прежнее сравнение конца шага давало true |
| 2460679.1188779487 | Луна / Венера | Ингресс раньше аспекта | true |
| 2460694.5634033154 | Солнце / Луна | Аспект раньше ингресса | false; прежнее сравнение конца шага давало true |
| 2460724.4540941776 | Солнце / Луна | Аспект раньше ингресса | false; прежнее сравнение конца шага давало true |

Три карты воспроизводят исправленный ложный флаг; четвёртая служит контролем события до аспекта.

Станции до/после и пограничное совпадение дополнительно покрыты синтетическими траекториями с независимыми временами. Для антисции Луны к фиксированной точке Венеры найден независимый корень на 20.8742564507 суток от JD 2460676.5; телесное расстояние в этот момент ≈136.433522°, точного птолемеевского аспекта нет. У независимого восхода Солнца сохранились определённые достоинства и неопределённые варианты триплицитета. В примере Региомонтана Сатурн сохраняет сырой V дом и получает трактуемый VI.

## Ограничения проверки

DOM, формы, ревизии и импорт/экспорт проверены jsdom; эфемериды — реальным браузерным WASM под Node. В среде `SITES_MANAGED_LINUX_CONTAINER=1` инструмент `cua_repl.js` отсутствует. По инструкции Sites автоматическое управление браузером другим способом не запускалось; новая визуальная проверка Chrome/Safari и физического iPhone не выполнялась.

Независимые Python-эталоны не являются ручной экспертной методической приёмкой. Страницы раннего Фроули указаны по переданной рецензии; полного самостоятельного аудита редакции 2014 нет. Общая полнота поиска, акцидентальных факторов и экспертных полномочий не заявляется. Дополнительные косвенные пути — кандидаты с ограниченным покрытием; окончательные YES/NO/TIMING заблокированы.

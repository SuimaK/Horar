## Что не проверено / не завершено

- В текущей среде npm registry недоступен: `npm install`, итоговый `vite build` и запуск WebAssembly на настоящем iPhone **не проходили интеграционной проверки**. GitHub Actions автоматически выполняет эти команды и прервёт публикацию при ошибках.
- Совпадение чисел Moshier WebAssembly с независимым PySwissEph по реальным динамическим траекториям в этом выпуске **не проверено**: базовые тесты берут независимые опорные позиции через контролируемые моки.
- ±0.5° относительно горизонта — инженерная страховка, а не утверждённый методический порог. Пограничная секта требует экспертной проверки.
- Не проведены физические проверки Safari, обновлений service worker и офлайн-режима.
- В v1.1, v1.2 **нет** контекстного синтеза результата хорара, срока или эффективности предсказаний. 88 семантических сценариев остаются невыполненными.
- При анализе профилей или методик нужно отдельно оценить лицензии и право на публичное размещение исходного кода; Swiss Ephemeris распространяется по AGPL-3.0.

**Вывод:** исходный проект для публикационной сборки готов на уровне логики. Полностью протестированным приложением Safari считать его до фактической сборки WASM и проверки на устройстве нельзя.

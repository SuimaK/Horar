# Хорар

Веб-приложение (PWA), которое строит карту неба на заданный момент и место и описывает её строение по правилам традиционной (хорарной) астрологии: положения, дома, достоинства, аспекты. Приложение не принимает вопросов и не даёт прогнозов.

Техническое задание: https://claude.ai/artifact/TH8ptW9W3qskG8ZDFfAmnT

Приложение написано заново и не наследует код предыдущей версии «Хорар» (она осталась в истории git).

## Этапы

1. **Каркас и форма ввода** (ТЗ, раздел 2) — готово.
2. **Расчётное ядро**: эфемериды, дома, объекты, существенные достоинства, секта (ТЗ 3.1–3.3, 3.5) — готово.
3. Аспекты по полуорбисам Лилли, фаза, моменты точности, рецепции, антисции.
4. Акцидентальное состояние, раздел «Луна», планетные часы.
5. Колесо карты и экраны, шаблоны описаний, автотест тона.
6. Архив, экспорт и импорт, офлайн-режим PWA, приёмочные проверки.

## Что уже работает

- Поля: дата (ДД.ММ.ГГГГ, 1800–2200), местное время (ЧЧ:ММ[:СС]), место из офлайн-справочника (≈23,5 тыс. городов от 15 000 жителей) или координаты вручную (десятичные градусы или °′″, N/S/E/W, с./ю./в./з.).
- Часовой пояс IANA определяется по месту (у города из справочника — его пояс, при ручных координатах — по карте границ поясов). Можно задать смещение UTC±ЧЧ:ММ вручную.
- Перевод в UTC по базе часовых поясов браузера с историей переводов часов. Строка проверки до построения: `19.11.2026 23:35 (UTC+03:00) = 20:35 UTC, 55°45′ N 37°37′ E`.
- Несуществующее время (пропущенный час) — ошибка с границами пропуска. Неоднозначное (повторный час) — обязательный выбор одного из двух моментов UTC.
- Широта вне ±65° — отказ с кодом `LATITUDE_OUTSIDE_VALIDATED_REGION`.
- Даты до 1970 года — предупреждение о надёжности исторических поясов.
- Светлая и тёмная темы, ширина от 360 px. Постоянная строка под картой: «Описание геометрии карты… Не является прогнозом и рекомендацией».

## Эфемериды

Как в приложении «Астро»: Swiss Ephemeris (файлы SE1 `sepl`/`semo`) используется только при сборке таблиц, кода Swiss Ephemeris в приложении нет. Скрипт `tools/ephemeris/build_tables.py` раскладывает положения Солнца, Луны, планет, узлов, нутацию, звёздное время и ΔT на 1799–2201 гг. в многочлены Чебышёва и пишет их в `public/ephemeris/` (8 файлов по 50 лет, около 0,9 МБ каждый). Приложение загружает только нужные 50 лет.

Положения в таблицах — без нутации и отклонения света: так ряды гладкие. Нутация добавляется из таблицы, отклонение света Солнцем — по той же формуле, что в Swiss Ephemeris. Расхождение со Swiss Ephemeris на 329 эталонных моментах (`tests/fixtures/swe-reference.json`) — меньше 0,01″ для всех планет и Луны, куспиды всех четырёх систем домов — меньше 0,01″.

Пересборка таблиц и эталонов (нужны `pyswisseph`, `numpy` и файлы `sepl_12/18.se1`, `semo_12/18.se1`):

```bash
python tools/ephemeris/build_tables.py --ephe ~/ephe --out public/ephemeris
python tools/ephemeris/make_reference.py --ephe ~/ephe --out tests/fixtures/swe-reference.json
```

## Таблицы метода

`src/method/*.json`: знаки, обители, экзальтации, изгнания, падения; триплицитеты по Дорофею; термы (птолемеевы по Лилли и египетские); фасы; баллы достоинств; планеты. У каждой строки указан источник.

## Разработка

```bash
npm ci
npm run dev        # локальный сервер
npm test           # тесты (Vitest)
npm run build      # проверка типов и сборка в dist/
```

`npm run data` генерирует справочник городов `src/data/cities.generated.json` (запускается автоматически перед dev, test и build). Русские названия городов вне России подобраны эвристикой из альтернативных названий GeoNames; ошибки исправляются в `src/data/city-name-overrides.json` (идентификатор GeoNames → название).

Структура:

- `src/core/time` — разбор даты и времени, перевод местного времени в UTC, форматирование.
- `src/core/geo` — координаты, справочник городов.
- `src/core/input` — проверка ввода, тексты ошибок, строка проверки.
- `src/core/astro` — таблицы эфемерид, положения, дома, достоинства, сборка карты.
- `src/method` — таблицы метода (JSON с источниками).
- `src/ui` — интерфейс (Preact).
- `tests` — тесты.

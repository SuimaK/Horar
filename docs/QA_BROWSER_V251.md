# Horar 2.5.1 — браузерная приёмка

Продолжение корректирующей версии 2.5 и интеграционных проверок PR #2.

## Изменения

- Создание ревизии из старой карты использует максимальный номер в группе + 1. Старые ревизии и их численные снимки сохраняются.
- Импорт принимает как полный `horary-iphone-archive-v1`, так и отдельный `horary-iphone-record-v1`, который приложение уже умеет экспортировать. Оба формата проходят одинаковую повторную проверку карты, защиту от подмены и дедупликацию. Существующая ревизия с иными исходными данными остаётся конфликтом.
- При открытии старой карты пересчитанный результат попадает в рабочий архив только после успешной записи в LocalStorage. При ошибке прежние данные и активная страница сохраняются; проверку можно повторить.
- Service worker использует отдельный кэш для своего origin и пути регистрации. Обновление удаляет только предыдущие кэши этого scope. HTML-заглушка разрешена только для навигации, не для WASM, JavaScript и JSON. Содержимое сборки определяет версию кэша.
- Ключ LocalStorage, форматы старых архивов, методические контракты и ограничения итогового прогноза сохранены.

## Воспроизведение

```bash
npm ci
npm test
npx playwright install --with-deps chromium webkit
npm run test:browser
```

В CI та же последовательность, с отдельными шагами сборки и `npx playwright test`. Настоящий production bundle обслуживается из `/Horar/`, без подмены расчётного модуля и эфемерид. Каждый тест использует отдельный браузерный контекст и синтетические вопросы. Рабочий архив пользователя не используется.

## Автоматизированная проверка

Три новые регрессии воспроизвели ошибки до исправления: коллизия номера старой ревизии, отказ импорта экспортированной карты, открытие пересчитанной карты после неудачной записи. После исправлений весь набор Node содержит 144 теста.

| Браузерный сценарий | Что проверяется |
|---|---|
| Карта у горизонта и офлайн | Реальный WASM, неопределённая секта, независимые достоинства, отсутствие итогового прогноза; перезагрузка без сети, открытие архива, новый расчёт без сети; отсутствующий WASM не получает HTML |
| Ревизии и резервные копии | R1 → R2 → открытие R1 → R3; исходный численный снимок; фактическое скачивание JSON карты и архива; восстановление в пустом хранилище и повторный импорт без дублей |
| Ошибки и сохранность | Ошибочная широта, поддельное разрешение прогноза, заполненное хранилище при импорте/открытии/новом расчёте; прежний архив и несохранённый текст остаются |
| Обновление офлайн-кэша | Старый кэш текущего scope удаляется; кэши другого приложения и другого пути Horar сохраняются |
| Тематические формы | Контакты, отношения, работа; реальные расчёты, открытие из архива, восстановление собственных полей и подтверждений при ревизии, отсутствие переноса сценария другой темы |

Пять сценариев запускаются в Chromium и WebKit при мобильных размерах iPhone 13: всего 10 проверок. Дополнительно проверяется отсутствие горизонтального переполнения страницы; снимки экрана и трассы при ошибках доступны в артефакте `browser-test-results` соответствующего GitHub Actions run.

## Пределы подтверждения

WebKit Playwright на Linux не заменяет Safari на физическом iPhone. Ручные M-01–M-05 из `QA_MANUAL_V201.md`, очистка данных iOS, установка на экран Домой и жизненный цикл Safari остаются неподтверждёнными. Проверки эфемерид и интерфейса не подтверждают предсказательную точность астрологии.

Публичная сборка в `browser-build` этой веткой не обновляется. Автоматические YES/NO/TIMING остаются отключены.

# Приёмка Horar 2.8 / v2.2 на iPhone Safari

**Состояние:** тестовая сборка отдельна от рабочей версии. В Safari нет права утверждать завершённую ручную приёмку без фактической проверки пользователем.

## Подготовка

Откройте тестовую сборку Horar 2.8. Перед импортом реальных данных **экспортируйте архив вопросов из действующей версии**. Закреплённая сборка может использовать тот же домен rawcdn.githack.com, но иной путь и иной scope PWA, а приложение с домашнего экрана iOS может хранить данные отдельно.

## Проверить

1. **Простой общий событийный вопрос.** Выберите EVENT, подтвердите обоснованные роли; постройте карту. На экране «Разбор» первым должен быть раздел «Развитие события»: краткий вывод и, при наличии, раскрываемые пути.
2. **Прямое совершенствование.** Если рассчитан точный будущий аспект, он должен быть кандидатом; отсутствие явных препятствий не должно превращаться в безусловное YES.
3. **Не найдены пути.** Если в проверенной области нет прямого аспекта, текст обязан подчеркнуть неполноту поиска, а не отвечать NO.
4. **Недостаточные роли.** Не назначайте дом или снимите галочку подтверждения. Программа должна объяснить, что требуется уточнение сигнификаторов, а не делать вывод.
5. **Тематический вопрос.** Выберите отношения, работу или потерянный предмет. Арбитр не должен применять общий YES/NO — нужен утверждённый тематический критерий.
6. **Достоинства и рецепции.** Вслед за арбитром должен отображаться понятный разбор v2.1 с указанием знака, дома и направленных рецепций. Неподтверждённый триплицитет должен оставаться неопределённым.
7. **Читаемость карты.** Скопление планет не должно приводить к наложению значков; должны работать увеличение круга и переключение аспектов.
8. **Архив.** Откройте старую сохранённую карту и экспортируйте её. Исходный текст, время, координаты, планеты и `source_chart_hash` не должны изменяться. Повторный импорт не должен создавать дублей.
9. **Геопоиск.** Проверьте поиск города по названию, UTC-смещение по дате вопроса и отказ в разрешении GPS. Передача GPS-координат внешнему сервису для уточнения названия города требует отдельного согласия.

## Фиксация

Для каждого пункта: PASS / FAIL / BLOCKED, модель iPhone, iOS, адрес тестовой сборки, скриншот при дефекте, поведение при обновлении страницы. Не объявляйте итоговую приёмку завершённой только по результатам автоматических тестов.

## Граница применения

Версия v2.2 **не утверждает** реальный исход события, чувства другого человека или точную дату. Коды `CANDIDATES_WITH_OPEN_REVIEW`, `NO_CANDIDATE_IN_INCOMPLETE_SCOPE` и другие — статусы вычислений и потребности в контекстной проверке, не прогнозы. Автоматические YES/NO и сроки пока запрещены.
